# Foodix PWA · dossier de départ

1. Dézippe ce dossier là où tu veux créer le projet.
2. Ouvre un terminal dans `foodix-pwa/` et lance `claude`.
3. Claude Code lit automatiquement `CLAUDE.md` (brief complet). Tu peux démarrer avec par exemple :

   > Lis CLAUDE.md, design/LIRE-LA-MAQUETTE.md et data/menu.json, puis initialise le projet Vite + React et construis l'accueil / menu en version téléphone d'après design/maquette/Menu.dc.html.

Avance ensuite étape par étape en suivant « Ordre de travail conseillé » dans `CLAUDE.md`.
